# Skillzza K-12 Website Typography & Styling System

Based on the Home Hero section, here is the standard design language that will be strictly followed across the entire website to maintain pixel-perfect consistency.

## 1. Global Font Family
- **Primary Font**: `'Poppins', sans-serif`
- **Used Weights**: 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold), 800 (ExtraBold)

## 2. Main Headings (Hero H1)
Used for the most important page titles.
- **Font-Weight**: 800
- **Font-Size**: `clamp(28px, 4.2vw, 74px)`
- **Line-Height**: `1.12`
- **Letter-Spacing**: `-0.5px`
- **Standard Color**: `#1A1A2E`
- **Highlight/Accent Color**: `#6C3CF7`

## 3. Sub-Headings / Lead Paragraphs
Used directly below main headings to describe the section.
- **Font-Weight**: 400
- **Font-Size**: `clamp(14px, 1.2vw, 20px)`
- **Line-Height**: `1.65`
- **Letter-Spacing**: `0.3px`
- **Standard Color**: `#84888B`

## 4. Card & Feature Titles
Used for individual component titles or section blocks.
- **Font-Weight**: 700
- **Font-Size**: `clamp(15px, 1.3vw, 20px)`
- **Standard Color**: `#1F2937`

## 5. Card & Feature Descriptions
Used for the descriptive text inside cards.
- **Font-Weight**: 400
- **Font-Size**: `clamp(12px, 0.9vw, 14px)`
- **Line-Height**: `1.5`
- **Standard Color**: `#6B7280`

## 6. Interactive Elements (Buttons)
- **Font-Weight**: 600
- **Font-Size**: `clamp(13px, 1vw, 17px)`

## 7. Badges & Labels
- **Font-Weight**: 700
- **Font-Size**: `clamp(10px, 0.75vw, 14px)`
- **Letter-Spacing**: `1.5px`
- **Standard Color**: White inside colored pills

> [!IMPORTANT]
> This is now memorized as the core source of truth. All future components, pages, and UI sections for this project will utilize these precise `clamp()` values and specific hex colors to guarantee 100% platform consistency.
